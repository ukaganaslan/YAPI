# Health AI - Co-Creation & Innovation Platform 🚀

Health AI, mühendisler ile sağlık profesyonellerini bir araya getiren, sağlık teknolojileri alanında inovasyonu hızlandırmayı amaçlayan bir iş birliği platformudur.

## ✨ Özellikler

- **Kurumsal Kayıt Sistemi:** Yalnızca `.edu` ve `.edu.tr` uzantılı e-posta adresleri ile güvenli kayıt.
- **Rol Bazlı Erişim:** Mühendis ve Sağlık Profesyoneli rolleriyle özelleştirilmiş deneyim.
- **İlan Panosu (Dashboard):** İhtiyaç duyulan uzmanlık alanlarına göre ilan oluşturma ve filtreleme (Yapım aşamasında).
- **Güvenli İlk Temas:** Gizlilik kuralları çerçevesinde iş birliği başlatma.

## 🛠️ Teknolojiler

- **Frontend:** React + Vite
- **Styling:** Tailwind CSS
- **Mock Backend:** JSON Server (Geliştirme aşamasında veritabanı simülasyonu için)
- **Versiyon Kontrol:** Git & GitHub
